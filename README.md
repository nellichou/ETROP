# ETROP
**Etrop** est une application qui se base sur la notion de l'Interface Homme Machine, elle permet la gestion d'utilisateurs et de leurs applications au sein d'une entreprise avec différents rôles.\
Ce projet est une maquette de l'application avec ses wireflows et ses wireframes.\
Il y a 4 utilisateurs type : - utilisateur normal (client),\
                        - utilisateur avancé (manager),\
                        - ressources humaines,\
                        - super utilisateur.\
Leurs rôles sont détaillées plus précisément dans le rapport.
